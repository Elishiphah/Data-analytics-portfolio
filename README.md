## Projects

### 1. Medical Appointment No-Shows — Exploratory Data Analysis

An exploratory analysis of medical appointment records using Python, Pandas, and Matplotlib.

**What I did:**

* Checked for missing values and duplicate records.
* Investigated unusual patient ages and waiting times.
* Compared missed appointment rates across age groups and gender.
* Examined attendance patterns by SMS reminders and waiting time.
* Created charts to present the findings.

**Tools:** Python, Pandas, Matplotlib

**Project repository:** [View CodeAlpha EDA Project](https://github.com/Elishiphah/CodeAlpha_EDA_Medical_Appointments)
